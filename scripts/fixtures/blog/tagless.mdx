A valid Blog post can be short. Tags, section headings, figures, and references are optional; leaving them out should not break the reading controls or the verification suite.

This fixture keeps the article body in ordinary Markdown. Copying or downloading the article should preserve these paragraphs, even though there is no contents panel to navigate.

Readers can still choose a comfortable text size and typeface. The same actions and shared header should work at desktop and narrow mobile widths.

The fixture appears only in a temporary verification build. It never changes the publication state of a real article and is removed when the checks finish.
