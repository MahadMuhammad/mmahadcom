## Copying and exporting

A code block needs an independent copy control. Its success state should confirm the action without moving adjacent content. A failure must leave the example available for manual selection.

```js
const result = [1, 2, 3].map((value) => value * 2);
console.log(result);
```

The article actions export this same content as Markdown. Relative image URLs and source links become portable URLs, while headings, tables, quotations, code, and references retain their meaning.

The test ends with enough article content to exercise scroll navigation. Opening the first contents link should bring its heading below the fixed navigation, regardless of the current scroll position or text size.
